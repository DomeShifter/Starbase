# Rules for working in this repository

- This repository will be public: never commit IP addresses, host names, credentials, deploy
  configuration or anything else about where it runs.
- Engines are not edited here. WordCraft changes are commits on DomeShifter/wordcraft branch
  `stardocs` ("<crate>: <what> (StarDocs NNNN)"), then `commit` in stardocs/upstream.pin.
- stardocs/Cargo.toml is generated by stardocs/scripts/gen-cargo.py: edit the script, not the file.
- Our own code compiles without warnings (clippy on the wasm target).
- Commits: what changed and why, in plain words.
