# Starbase 0.2.0

**The first release you can install on Linux as a desktop program.** Starbase Drive (your files),
Starbase Sheets (spreadsheets), Starbase Docs (documents) and Starbase Slides (presentations)
now come as one desktop package that works on its own, with files on your computer, and can
also connect to your own Starbase server to share files with other people.

Starbase is still an **early preview**: it works and we use it every day, but expect rough edges,
keep backups of files that matter, and please
[tell us what breaks](https://github.com/DomeShifter/Starbase/issues).

## What's new

| App | New in 0.2.0 |
|---|---|
| **Linux desktop** | Install from Starbase's own Flatpak repository (updates arrive with `flatpak update`), or download one AppImage file. Every Linux download is signed, so you can check it really came from us. |
| **Starbase Slides** (new) | Open, edit and save PowerPoint (`.pptx`) files, on the server in your browser and in the desktop program. Comments, a full-screen slideshow and a presenter view. |
| **Starbase Sheets** | A pivot table editor like Google Sheets', alternating row colours, Smart Fill suggestions (Ctrl+Shift+Y), small charts (`SPARKLINE`) and pictures (`IMAGE`) inside cells, moving rows up and down, and sorting or filtering by colour. |
| **Starbase Docs** | File › Make a copy, File › Download in every format (Word, OpenDocument, Rich Text, PDF, plain text, web page, Markdown), a picture toolbar (crop, replace, text wrapping) and your own default paragraph styles. |
| **Starbase Drive** | "View as photos": a folder as a grid of pictures, with a full-screen viewer and a slideshow (turned on per folder). A new sign-in page and a Google-style account menu. |
| **Windows** (preview) | A first, unsigned installer to try out: see "Windows" below. |

Fixed: a save to the server that failed is now tried again by itself, even while the window is in
the background; a link opened while signed out goes back to that page after you sign in; the
server keeps the right versions when many saves arrive at once.

The full list is in the [changelog](https://github.com/DomeShifter/Starbase/blob/v0.2.0/CHANGELOG.md).

## How to install

### Linux: Flatpak (recommended)

Flatpak keeps Starbase up to date for you and runs it in a sandbox. In a terminal:

```sh
flatpak install --user --from https://domeshifter.github.io/Starbase/starbase.flatpakref
```

Starbase Drive, Sheets, Docs and Slides then appear in your app menu. Updates come with
`flatpak update` (or your software centre). This is **Starbase's own repository, not Flathub**;
Flatpak checks every download against our signing key, which the `.flatpakref` file carries.
The shared parts Starbase runs on (the "runtime") come from Flathub, so Flathub needs to be set up
on your computer (most distributions do this already).

Check the version you got: `flatpak info io.github.DomeShifter.Starbase` should say
`Version: 0.2.0`.

### Linux: AppImage (one file, no installing)

1. Download `starbase-0.2.0-linux-x86_64.AppImage` from the files below.
2. Make it runnable: right-click › Properties › "Allow executing as program", or
   `chmod +x starbase-0.2.0-linux-x86_64.AppImage`.
3. Double-click it. It opens Starbase Drive.

It runs on most Linux systems from 2022 onwards (Ubuntu 22.04, Debian 12, Fedora, and newer).

**Check that the file really is ours (recommended).** Every Linux file on this page is signed with
the Starbase release key. Download `starbase-release-signing.asc` from the
[repository](https://github.com/DomeShifter/Starbase/blob/v0.2.0/packaging/linux/starbase-release-signing.asc),
plus `SHA256SUMS` and `SHA256SUMS.asc` from this page, then:

```sh
gpg --import starbase-release-signing.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
```

You should see **"Good signature from Starbase release signing"**, and the key's fingerprint must
be `7704 529F 91C0 B0CE C578  9097 F9BF 4A64 BA9E 1715`. Then `sha256sum` should print `OK`
for the files you downloaded. (gpg also warns that the key is "not certified with a trusted
signature": that is normal for a key you have just imported; the fingerprint is what matters.)

### Your own server (Docker)

One Docker image holds the whole suite and keeps your files as ordinary `.xlsx`, `.docx` and
`.pptx` files:

```sh
mkdir -p ~/starbase/data ~/starbase/backups
sudo chown 1000:1000 ~/starbase/data ~/starbase/backups
docker run -d --name starbase --restart unless-stopped -p 8080:8080 \
  --memory 1536m --memory-swap 1536m \
  -v ~/starbase/data:/data -v ~/starbase/backups:/backups \
  ghcr.io/domeshifter/starbase:0.2.0
docker logs starbase   # shows the setup code for the first (owner's) account
```

Then open `http://<your server>:8080`. Already running 0.1.0? `docker pull
ghcr.io/domeshifter/starbase:0.2.0`, then remove and start the container again with the same
folders: your files stay where they are. Step-by-step guides for Docker Compose, Proxmox, TrueNAS
SCALE and Unraid: [docs/install](https://github.com/DomeShifter/Starbase/tree/v0.2.0/docs/install).

To use the desktop program with your server: in Starbase Drive, open the account menu at the top
right, choose **Connect to a server…** and enter the server's address.

### Windows: unsigned preview

> **Preview only.** The Windows programs work, but they are **not signed yet**, and they are less
> tested than the Linux ones. Use them to try Starbase, not yet for important work.

Two downloads, both for 64-bit (x64) Windows:

- `starbase-0.2.0-x64-setup.msi`: an installer just for you (no administrator needed). Start menu
  entries for Starbase Drive, Sheets and Docs, and "Open with" choices for spreadsheets and
  documents; it never changes your default apps. Uninstall in Settings › Apps; your files stay.
- `starbase-0.2.0-windows-x64-portable.zip`: the same programs with nothing to install. Unzip and run
  `starsheets.exe` (Drive and Sheets) or `stardocs.exe` (Docs).

**Why Windows warns you:** Windows SmartScreen shows "Windows protected your PC" for programs
from a publisher it does not know yet, and an unsigned program has no publisher at all. This is
expected for this preview. Choose **More info**, then **Run anyway**. If Windows blocks the files
after unzipping, right-click the zip *before* unzipping, choose Properties and tick **Unblock**.
Signed Windows programs are planned ([code signing policy](https://github.com/DomeShifter/Starbase/blob/v0.2.0/docs/code-signing-policy.md)).

Windows itself can't check these files yet, but you can: both are listed in `SHA256SUMS` and have
a `.asc` signature from the Starbase release key, like the Linux files (see "Check that the file
really is ours" above).

## Known limitations

- **Early preview.** Keep backups of files that matter (the server's built-in backups help).
- **Live co-editing** (several people typing at once) works in Starbase Sheets only. In Docs and
  Slides, one person should edit a file at a time.
- **Starbase Slides is brand new**: simple presentations work well; complicated PowerPoint files
  (animations, embedded videos, unusual layouts) may not look the same.
- **Flatpak: files on your computer live in `Documents/Starbase`.** The sandbox lets Starbase see
  only that folder (it creates it). To open a file from elsewhere, copy it there, or use a server.
- **AppImage menu entries:** tools that add AppImages to your menu (Gear Lever, AppImageLauncher)
  add only Starbase Drive. Separate Sheets, Docs and Slides menu entries, and double-clicking
  files in your file manager, work fully with the Flatpak.
- **Windows** is an unsigned preview without Starbase Slides. **Mac**: not yet.
- **Not on Flathub** for now: install from our own repository as shown above.
