# Fonts

All SIL Open Font License 1.1 (licence files beside them), from storytold/craft-fonts (the
collection DeckCraft's own builds take theirs from) and, for Carlito and Caladea, the same files
as StarDocs (`stardocs/app/fonts/office`). How they are used: `src/fonts.rs`.

| File(s) | For | Where |
|---|---|---|
| `Inter-Regular.ttf`, `Inter-Bold.ttf` | DeckCraft's default theme font | in the program |
| `more/Inter-Italic.ttf` | Inter italic | fetched after start |
| `more/LiberationSans-*.ttf` | Arial (same widths; the design StarDocs' Arimo also has) | fetched after start |
| `more/Carlito-*.ttf` | Calibri (same widths) | fetched after start |
| `more/Caladea-*.ttf` | Cambria (same widths) | fetched after start |
