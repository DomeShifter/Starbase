# Security

If you find a security problem, please report it privately: open the repository's **Security** tab
and choose **Report a vulnerability**. Please don't open a public issue for it.

I'll reply as soon as I can, fix it, and credit you in the release notes if you'd like.

Please note: StarSheets is an early preview. The self-hosted file server is meant to sit on a private
network or behind a login; don't expose it to the internet on its own until a release says it has
its own login.
