# Code of conduct

Starbase Sheets follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, welcome people whatever their experience or
background, and keep criticism about the work, not the person. Harassment, insults and personal
attacks aren't welcome here.

If something goes wrong, please report it privately using GitHub's **Report content** option on the
comment or issue, or by opening a private report from the repository's **Security** tab. Reports are
read by the maintainer and kept confidential.
