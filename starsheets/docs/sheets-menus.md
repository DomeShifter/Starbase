# Google Sheets menus (checked against live Sheets, 2026-11-21)

Taken from screenshots of a live Google Sheet opened as a link editor, which is why account-only
items are greyed out. `▸` = opens a submenu, `—` = divider, shortcuts are shown on the right in grey.
This replaces the "(from memory)" menu rows in sheets-reference.md.

## How the menus look
| Part | Sheets |
|---|---|
| Menu bar | Plain text, 14 px, no boxes; the open menu's title gets a light grey rounded fill |
| Menu panel | White, ~8 px corner radius, soft shadow, no border; ~320 px wide (wider when a shortcut needs it) |
| Item row | ~32 px tall; 20 px outline icon at the left (Material Symbols), label 14 px starting ~40 px in |
| Shortcut | Right-aligned, grey (#80868b-ish), same size as the label |
| Submenu | Small grey `▸` at the right edge |
| Divider | 1 px light grey line with ~8 px space above and below, edge to edge |
| Disabled | Icon and label in light grey |
| Badge | Green "New" pill on the right (Record video, Data connectors) |
