### Fixed
- Sheets, Docs and Slides: Ctrl+H, Ctrl+K, Ctrl+U and Ctrl+W no longer edit text in a text box the old Emacs way (Backspace, delete to end of line, delete to start of line, delete the word before). They are taken out of the input before the text box sees them. In Sheets, Ctrl+H opens Find and replace while editing a cell too.
