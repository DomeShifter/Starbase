### Added
- Photo Mode is its own room: dark by default (a sun/moon switches it), its own camera-aperture icon, no Drive list or New menu, a photo-only top bar with "Search photos", a SET switch (This folder / This folder and subfolders / Everything) and a Type filter (JPEG, PNG, HEIC, RAW, GIF, WebP, Video). On a phone the switches fold into one menu.
- The photo list can ask for every picture the person may see (`GET /api/photos?all=1`).

### Changed
- Removed the "Include subfolders" button from Photos: the SET switch replaces it.
