### Added
- Photos: an editor for pictures. In the viewer press Edit (or E): crop (aspect presets, turn,
  flip, straighten, drag the corners), adjust (exposure, contrast, highlights, shadows,
  saturation, vibrance, warmth, tint; double-click a slider to reset it) and six filters with an
  amount. Undo/redo (Ctrl+Z / Ctrl+Shift+Z), hold \ or Compare to see the original, Reset,
  Cancel (asks first if there are changes), Save (the photo file itself never changes) and
  "Save a copy…" (a new, edited file, location removed by default). Pictures in a folder that
  can't be changed say why Save is off; a save that crosses another one offers to reload.
