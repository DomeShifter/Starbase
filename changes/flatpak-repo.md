### Added
- Linux: Starbase's own signed Flatpak repository on GitHub Pages, published by each release:
  `flatpak install --user --from https://domeshifter.github.io/Starbase/starbase.flatpakref`,
  then updates with `flatpak update` (Flathub is not an option for now).
- Linux: the `.flatpak` bundle is attached to each release too, signed and listed in `SHA256SUMS`.
