### Added
- Starbase Slides on the desktop (`starslides`): opens and saves PowerPoint (.pptx) files on this computer, saving by itself a moment after each change; a new presentation is "Untitled presentation.pptx" in Documents/Starbase. File has New presentation, Open…, Open recent and Connect to a server…, and presentations on a connected Starbase server open in it too.
- Starbase Drive on the desktop opens .pptx files in Starbase Slides and has "New presentation" (in a folder on this computer or on the server).
- The AppImage and the Flatpak include Starbase Slides, with its own menu entry, and PowerPoint files open in it from the file manager.
