### Fixed
- Photos editor: after "Save a copy" the original counts as unchanged, so leaving it no longer warns "exiting without saving" (changes made after the copy still do).
- Photos: a picture that was moved or deleted no longer shows the raw text "no such file" at the top; it says "That picture isn't there any more."
- Failed picture and file requests now leave one line in the browser console (method and path) and in the server log, so an unexplained error can be traced.
